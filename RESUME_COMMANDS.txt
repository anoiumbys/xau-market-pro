# XAU Market Pro - Quick Resume Commands

## Current State: Phase M0 Foundation ~70% complete
Backend models, services, events, jobs, middleware, resources, requests, and 4/10 API controllers done.

## Next Commands to Run

```bash
cd xau-market-pro

# 1. Backend setup
cd backend
composer install
cp .env.example .env
php artisan key:generate

# 2. Create migrations (7 tables)
php artisan make:migration create_users_table --create=users
php artisan make:migration create_markets_table --create=markets
php artisan make:migration create_subscriptions_table --create=subscriptions
php artisan make:migration create_price_alerts_table --create=price_alerts
php artisan make:migration create_trade_journal_table --create=trade_journal
php artisan make:migration create_market_parameters_table --create=market_parameters
php artisan make:migration create_audit_logs_table --create=audit_logs

# 3. Edit each migration file with schema from blueprint
# 4. Run migrations
php artisan migrate

# 5. Create seeders
php artisan make:seeder UserSeeder
php artisan make:seeder MarketSeeder
php artisan make:seeder MarketParameterSeeder
php artisan make:seeder SubscriptionPlanSeeder

# 6. Run seeders
php artisan db:seed

# 7. Install frontend
cd ../frontend
npm install

# 8. Install contracts
cd ../contracts
npm install

# 9. Sync contracts (generates TypeScript types)
npm run sync

# 10. Start dev servers
# Terminal 1: cd backend && php artisan serve
# Terminal 2: cd backend && php artisan websockets:serve
# Terminal 3: cd frontend && npm run dev
```
